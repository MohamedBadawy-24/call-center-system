### `tests/auth.test.js`
**Authentication & Session**
- `POST /auth/login` with valid credentials → expect `200` + JWT token in response
- `POST /auth/login` with wrong password → expect `401`
- `POST /auth/login` with suspended account → expect `403`
- `GET /auth/me` with valid token → expect `200` + correct user object
- `GET /auth/me` with no token → expect `401`
- `GET /auth/me` with expired/malformed token → expect `401`
- Rate limiting: fire 10 rapid login attempts with wrong password → expect `429` on the final attempts

### `tests/agent-workflow.test.js`
**Full Agent Call Workflow (W1)**
Run these in order as a stateful sequence using `beforeAll` / `afterAll`:

1. Set Agent A status to `active` → expect `statusStartedAt` to be written
2. Call `GET /agent/next-number` → expect a phone number assigned with `sessionStatusStartedAt` matching agent's `statusStartedAt`
3. Call `POST /agent/precall-complete` with a valid payload (contacted, age ≥ 18, no `interviewOutcome`) → expect:
   - `200` response
   - `PrecallCompletion` document created in DB with `disqualified: false` (**B1 regression**)
   - `serialNumber` written to both `PrecallCompletion` and `PhoneNumber`
4. Call `POST /agent/precall-complete` with a blank age field → expect the age gate to return null/invalid, not `0` (**B2 regression**)
5. Call `POST /response` with valid survey answers and `interviewOutcome: 'completed'` → expect:
   - `200` response
   - `Response` document created
   - `PhoneNumber.status` updated to `'completed'`
   - `PrecallCompletion` final outcome updated
   - `Draft` for this serial deleted
   - All three writes confirmed in DB (transaction integrity — **B3/B4 regression**)
6. Call `POST /response` a second time with the same `serialNumber` → expect `409` or appropriate rejection (duplicate guard)
7. Set Agent A status to `break` then attempt `GET /agent/next-number` → expect `403` (R1 enforcement)

- Read every relevant source file before writing a test for it
- Tests must not hardcode ObjectIds — fetch them dynamically from the API or DB in `beforeAll`
